바이브 코딩이란?

코드를 직접 쓰는 대신, AI에게 "이런 걸 만들어줘"라고 대화하며 프로그램을 만드는 방식입니다.

What is Vibe Coding?

Instead of writing code yourself, you describe what you want to an AI in plain language and it builds it for you.

❌ 전통적 코딩❌ Traditional Coding

문법 학습 3~6개월 → 개발환경 설치 → 직접 코드 작성 → 에러 직접 해석 → 실전까지 6개월~1년Learn syntax 3-6 months → Setup dev environment → Write code → Debug errors → 6 months to a year until production

✅ 바이브 코딩✅ Vibe Coding

일상 언어로 AI에게 설명 → AI가 코드 생성 → "이것 좀 바꿔줘"로 수정 → 에러도 AI에게 "고쳐줘" → 첫날부터 결과물 가능Explain to AI in plain language → AI generates code → "Change this" to modify → "Fix this" for errors → Results from day one

Write Your AI Prompt

나쁜 요청 vs 좋은 요청Bad Request vs Good Request

❌ 안 되는 요청❌ Bad Request

"엑셀 정리해줘" — 뭘 정리?
"보고서 자동화해줘" — 어떤 보고서?"Clean up the Excel" — Clean up what?
"Automate the report" — Which report?

✅ 좋은 요청✅ Good Request

"첨부한 매출.xlsx에서 B열이 서울인 행만 필터링해서 새 엑셀로 저장해줘""Filter rows where column B is 'Seoul' from the attached sales.xlsx and save as a new Excel file"

프롬프트 4원칙4 Prompt Principles

01

맥락 제공Give Context

02

절차 분해Break It Down

03

결과물 명시Specify Output

💡

샘플 데이터: 민감 데이터 대신 AI에게 "이 구조와 같은 더미 데이터 20행 만들어줘"라고 요청하세요.Sample Data: Instead of sensitive data, ask AI to "generate 20 rows of dummy data with this structure".

STEP 04

Execute & Iterate

Send to AI, check, modify via conversation. 5-10 iterations is normal.
